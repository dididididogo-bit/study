# Diversidade celular

## A célula e a teoria celular
- **1663 — Robert Hooke** observou cortes de **cortiça** (viu as paredes celulares) e usou pela primeira vez o termo **«célula»**.
- **1839 — teoria celular** (graças à evolução da microscopia):
  - a célula é a **unidade estrutural e funcional** de todos os seres vivos;
  - todas as células resultam de **células preexistentes** (divisão celular);
  - a célula contém **informação genética** passada às células-filhas;
  - as **reações metabólicas** ocorrem no interior das células.

:::key
O desenvolvimento tecnológico do **microscópio** (maior poder de **ampliação** e melhor **resolução**) permitiu observar com mais detalhe os organelos e conhecer melhor a **constituição e estrutura da célula**.
:::

## Microscópio ótico composto
**Partes:** ocular · tubo (canhão) · revólver · objetivas · braço (coluna) · platina com pinças · condensador e diafragma · fonte de luz · parafuso **macrométrico** · parafuso **micrométrico** · pé (base).

:::steps
**Como observar**
1. Verificar que está colocada a **objetiva de menor ampliação**.
2. **Iluminar** o campo; abrir/fechar o **diafragma** para regular a luz.
3. Colocar a **preparação** na platina.
4. Com o **macrométrico**, aproximar lentamente a platina da objetiva.
5. Olhar pela **ocular** e afastar lentamente até ver a primeira imagem.
6. Tornar a imagem **nítida** com o **micrométrico**.
:::

## Organismos
- **Unicelulares:** uma só célula (ex.: bactérias).
- **Pluricelulares (multicelulares):** duas ou mais células.

## Tipos de células
| | **Procarióticas** | **Eucarióticas** |
|---|---|---|
| Complexidade | **Muito simples**, pequenas | **Complexas**, maiores |
| Organelos membranares | **Não** | **Sim** |
| Material genético (ADN) | Disperso no citoplasma, no **nucleoide** | Dentro de um **núcleo** (membrana nuclear) |
| Exemplos | **Bactérias** e arqueobactérias | **Protistas, fungos, plantas e animais** |

**Estruturas da célula procariótica:** fímbrias (adesão), ribossomas (síntese de proteínas), parede celular (proteção), citoplasma, membrana celular, flagelo (mobilidade), nucleoide (material genético).

**Eucarióticas animais vs. vegetais:**
- **Animais:** **sem cloroplastos nem parede celular**; vários vacúolos **pequenos**.
- **Vegetais:** **com cloroplastos e parede celular**; normalmente **um grande vacúolo**.

## Organelos e funções
| Estrutura | Função |
|---|---|
| **Membrana celular** | Delimita a célula e **regula a entrada e saída** de substâncias |
| **Citoplasma** | Meio intracelular (espaço interno) que contém os organelos |
| **Núcleo** | Contém o **material genético (ADN)** e controla a atividade celular |
| **Parede celular** | Confere **proteção** (e forma) à célula |
| **Mitocôndria** | **Respiração celular** → produção de **energia** |
| **Cloroplasto** | **Fotossíntese** |
| **Vacúolo** | Reservatório de **água e outras substâncias** |
| **Complexo de Golgi** | **Transformação de proteínas** |
| **Retículo endoplasmático** | Produção e armazenamento de proteínas; síntese de membranas |
| **Ribossomas** | Síntese de proteínas |

| | Procariótica | Eucariótica animal | Eucariótica vegetal |
|---|---|---|---|
| Membrana celular | ✔ | ✔ | ✔ |
| Citoplasma | ✔ | ✔ | ✔ |
| Ribossomas | ✔ | ✔ | ✔ |
| Núcleo | ✗ | ✔ | ✔ |
| Parede celular | ✔ | ✗ | ✔ |
| Mitocôndrias | ✗ | ✔ | ✔ |
| Cloroplastos | ✗ | ✗ | ✔ |
| Vacúolo | ✗ | ✔ (pequenos, numerosos) | ✔ (um, grande) |
| Complexo de Golgi | ✗ | ✔ | ✔ |
| Retículo endoplasmático | ✗ | ✔ | ✔ |

:::tip
**Truques do caderno:** membrana, citoplasma (e ribossomas) são **comuns a todas**. O **núcleo** só falta nas **procarióticas**. A **parede celular** só falta nas **eucarióticas animais**. Os **cloroplastos** só existem nas **eucarióticas vegetais**.
:::

## Biodiversidade e níveis de organização biológica
**Biodiversidade** = enorme variedade de organismos, organizada do nível mais simples ao mais complexo:

| Nível | Definição |
|---|---|
| **Átomo** | Unidade básica da matéria |
| **Molécula** | Conjunto de átomos ligados entre si |
| **Célula** | Unidade básica dos seres vivos |
| **Tecido** | Conjunto de células com a mesma função |
| **Órgão** | Conjunto de tecidos com determinada função |
| **Sistema de órgãos** | Conjunto de órgãos interligados responsáveis por uma função |
| **Organismo** | Conjunto de sistemas de órgãos que funcionam como um todo |
| **População** | Organismos da **mesma espécie** que vivem no mesmo local |
| **Comunidade** | Diferentes **populações** que habitam um local e interagem |
| **Ecossistema** | Seres vivos de diferentes espécies que se relacionam entre si **e com o ambiente** |
| **Biosfera** | Conjunto de **todos os ecossistemas** da Terra |

:::tip
Ordem: **Átomo → Molécula → Célula → Tecido → Órgão → Sistema de órgãos → Organismo → População → Comunidade → Ecossistema → Biosfera**.
:::
